Introduction to Core Mathematics

Core Mathematics is the study of fundamental mathematical concepts and operations that form the foundation for all advanced mathematics, science, and engineering. In Senior High School, students engage with interconnected topics including real numbers, indices, surds, logarithms, sets, algebra, trigonometry, matrices, vectors, calculus, sequences, probability, statistics, and geometry.

Mathematics develops critical thinking, problem-solving skills, and logical reasoning. Every topic in this curriculum builds upon previous knowledge, creating a comprehensive framework for understanding patterns, relationships, and structures in both abstract and real-world contexts. From calculating compound interest in finance to modeling population growth in biology, from designing bridges in engineering to analyzing data in medicine, core mathematics provides the essential tools.

The study of mathematics teaches precision in thought and expression, the importance of proof and verification, and the power of generalization from specific examples. Whether pursuing science, technology, economics, medicine, or any technical field, mastery of core mathematics is indispensable. This page presents 16 major topics, each developed with definitions, rules, examples, diagrams, and applications to deepen understanding.

Real Numbers

The real number system includes all numbers that can be placed on an infinite number line. This set is the union of natural numbers, whole numbers, integers, rational numbers, and irrational numbers. In SHS, it is important to recognize each part and understand how they nest inside each other.

Natural numbers are counting numbers: 1, 2, 3, 4, ... Whole numbers add zero: 0, 1, 2, 3, ... Integers extend whole numbers to negatives: ... -3, -2, -1, 0, 1, 2, 3 ... Rational numbers are fractions and repeating or terminating decimals, written as a ratio of integers. Irrational numbers are decimals that never repeat and never terminate; examples include √2, π, and e.

One crucial property of the real numbers is density. Between any two real numbers there is always another real number. This means the line is continuous, and there is no gap between numbers. The completeness property of the real numbers makes calculus possible and ensures that every bounded increasing sequence converges to a real limit.

SHS students should also learn how to compare and order real numbers correctly. When comparing fractions, use common denominators or convert to decimals. When comparing irrational numbers, approximate them or use algebraic reasoning. For example, recognize that √5 is between 2 and 3 because 2² = 4 and 3² = 9.

Real numbers form a complete, ordered field that enables all of mathematics.

Mathematical Foundation

Natural Numbers, Whole Numbers, and Integers

Natural numbers are the foundation of counting and are the first numbers learned. They are 1, 2, 3, 4, 5, ... and continue indefinitely. Some definitions include 0, making them 0, 1, 2, 3, ... The set of natural numbers is denoted by ℕ. These numbers form a discrete set with no gaps between consecutive integers.

Whole numbers extend natural numbers by including zero. They are 0, 1, 2, 3, 4, ... denoted by ℤ₀. Zero has special properties: adding zero to any number gives the same number (additive identity), and multiplying any number by zero gives zero.

Integers include positive numbers, negative numbers, and zero: ... -3, -2, -1, 0, 1, 2, 3, ... denoted by ℤ. Integers are closed under addition, subtraction, and multiplication, meaning the result of these operations on any two integers is always an integer. Division is not closed: 3 ÷ 2 = 1.5, which is not an integer.

The ordering of integers is clear: positive integers are greater than zero, negative integers are less than zero, and -2 < -1 < 0 < 1 < 2. This ordering extends to other number types and is fundamental to inequalities.

Rational Numbers and Irrational Numbers

Rational numbers are numbers that can be expressed as the ratio of two integers, where the denominator is non-zero. They are denoted by ℚ. Examples include 1/2, 3/4, -5/3, and 0. Every integer is rational because n = n/1. Rational numbers include terminating decimals like 0.5 and repeating decimals like 0.333...

Irrational numbers are real numbers that cannot be expressed as a ratio of integers. Their decimal representations never terminate and never repeat. Famous examples include π ≈ 3.14159..., e ≈ 2.71828..., and √2 ≈ 1.41421... Most square roots of non-perfect squares are irrational.

The set of rational and irrational numbers together form the real numbers ℝ. This distinction is crucial in mathematics because irrational numbers, while impossible to write exactly as decimals, are still definite real values with precise mathematical properties. Exact mathematical work requires keeping surds like √2 in symbolic form rather than rounding to decimals.

The Real Number Line and Properties

The real number line is a visual representation of all real numbers arranged in order from left to right. The origin is at 0, negative numbers extend to the left, and positive numbers extend to the right. Every real number corresponds to exactly one point on the line, and every point on the line corresponds to exactly one real number.

Key properties of real numbers include commutativity (a + b = b + a), associativity ((a + b) + c = a + (b + c)), distributivity (a(b + c) = ab + ac), and the existence of inverses (every number a has an additive inverse -a such that a + (-a) = 0).

The distance between two points a and b on the number line is |a - b|, the absolute value of their difference. This concept is essential for understanding intervals, inequalities, and functions. The absolute value function treats all numbers as their positive distance from zero.

Indices

Indices, also called exponents or powers, describe repeated multiplication of the same number. The expression a^n reads "a raised to the power of n" and means a is multiplied by itself n times. For example, 3^4 = 3 × 3 × 3 × 3 = 81. Here 3 is the base and 4 is the index.

The laws of indices are key to SHS mathematics. They allow us to simplify expressions and rewrite them in compact forms. Important rules include: • a^m × a^n = a^(m+n) • a^m ÷ a^n = a^(m-n) • (a^m)^n = a^(mn) • (ab)^n = a^n b^n

Zero and negative indices extend the index rules to a complete system. Any non-zero number raised to the zero power equals one: a^0 = 1, provided a ≠ 0. Negative exponents represent reciprocal powers: a^(-n) = 1/a^n. This is extremely useful when solving equations and simplifying algebraic fractions.

The laws of indices unify the algebraic manipulation of powers and exponentials.

Algebraic Foundation

The Laws of Indices

The first law states that when multiplying powers of the same base, add the exponents: a^m × a^n = a^(m+n). For example, 2³ × 2⁵ = 2^(3+5) = 2⁸ = 256. This works because we are counting the total number of times the base is multiplied.

The second law states that when dividing powers of the same base, subtract the exponents: a^m ÷ a^n = a^(m-n). For example, 5^7 ÷ 5^3 = 5^(7-3) = 5⁴ = 625. If the exponent in the numerator is smaller than in the denominator, the result is a negative exponent.

The third law states that when raising a power to another power, multiply the exponents: (a^m)^n = a^(mn). For example, (2³)² = 2^(3×2) = 2⁶ = 64. This rule is essential in algebra when dealing with polynomials and algebraic expressions.

The fourth law states that when raising a product to a power, each factor is raised to that power: (ab)^n = a^n × b^n. For example, (3×4)² = 3² × 4² = 9 × 16 = 144. Similarly, (a/b)^n = a^n / b^n.

Zero and Negative Indices

Zero indices arise naturally from the second law. If we compute a^m ÷ a^m using the division law, we get a^(m-m) = a⁰. But a^m ÷ a^m = 1 for any non-zero a. Therefore, a⁰ = 1 for all a ≠ 0. This is a fundamental definition that extends the pattern of exponents.

Negative indices appear when the divisor has a larger exponent than the dividend. For example, 2³ ÷ 2⁵ = 2^(3-5) = 2^(-2). Using reciprocals, 2³ ÷ 2⁵ = 8 ÷ 32 = 1/4 = 1/2². Therefore, a^(-n) = 1/a^n. Negative exponents indicate the reciprocal of the positive exponent.

This definition is consistent and powerful. It allows us to write expressions like 1/x² as x^(-2), which can then be manipulated using the laws of indices. Simplifying expressions with negative exponents requires moving terms between numerator and denominator to change the sign of the exponent.

Fractional Indices

Fractional indices connect exponent notation with roots. The expression a^(1/2) is defined as the square root of a: a^(1/2) = √a. Similarly, a^(1/3) = ∛a, the cube root of a. More generally, a^(1/n) = ⁿ√a, the nth root of a.

More complex fractional indices combine roots and powers. The expression a^(m/n) means "raise a to the power m, then take the nth root" or equivalently "take the nth root of a, then raise to the power m": a^(m/n) = ⁿ√(a^m) = (ⁿ√a)^m. For example, 8^(2/3) = ∛(8²) = ∛64 = 4, or 8^(2/3) = (∛8)² = 2² = 4.

This connection between fractional indices and roots is crucial. It means that surds and indices are two notations for the same concepts. Mastering indices helps with surds, and vice versa. All the laws of indices apply to fractional indices as well.

Scientific Notation

Scientific notation is a practical application of indices that is essential in science and engineering. Very large or very small numbers are written as a × 10^n, where 1 ≤ a < 10 and n is an integer. For example, the speed of light is approximately 3.0 × 10^8 m/s, and the size of an atom is approximately 1 × 10^(-10) m.

To convert a large number to scientific notation, move the decimal point left until one non-zero digit remains before it, then count how many places it moved. That count is the positive exponent. For example, 56,000 = 5.6 × 10^4 because the decimal moved 4 places to the left.

For small numbers, move the decimal point right until one non-zero digit is before it, then count how many places it moved. That count is the negative exponent. For example, 0.00038 = 3.8 × 10^(-4) because the decimal moved 4 places to the right.

Scientific notation keeps calculations manageable and connects algebraic thinking with real-world science. It is used in all scientific fields to represent quantities with vastly different magnitudes on the same scale.

Surds

Surds are irrational square roots and other roots that cannot be simplified to exact rational numbers. For example, √2, √3, and √5 are surds. In SHS, surds appear when exact values are required instead of decimal approximations. A surd must be written in its simplest form, with no perfect square factors remaining inside the root sign.

The symbol √ represents the square root, ∛ represents the cube root, and ⁿ√ represents the nth root. The number inside the root is called the radicand. Surds obey specific rules for simplification, addition, multiplication, division, and rationalization.

Because surds are exact expressions, they are preferred in mathematics over decimal approximations when precision matters. SHS students should practice manipulating surds until the rules become natural, especially when surds appear in geometry proofs and algebraic simplification.

Surds preserve exact values in mathematics where decimals would introduce error.

Mathematical Precision

Definition and Classification of Surds

A surd is an irrational root of a positive integer that cannot be simplified to a rational number. The most common surds are quadratic surds (square roots of non-perfect squares). Examples include √2 ≈ 1.414..., √3 ≈ 1.732..., and √5 ≈ 2.236...

Surds can be classified as simple surds (single root of an integer) or compound surds (expressions containing multiple surds). Like surds have the same radicand and index. For example, 3√5 and 2√5 are like surds and can be combined, but √2 and √3 are unlike surds and cannot be combined.

A surd is in simplest form when the radicand has no perfect square factors (for square roots), no perfect cube factors (for cube roots), and so on. For example, √8 is not in simplest form because 8 = 4 × 2, and √4 = 2, so √8 = 2√2.

Simplifying Surds

To simplify a surd, factor the radicand into the largest perfect power factor possible. For √50: 50 = 25 × 2 = 5² × 2, so √50 = √(5² × 2) = 5√2. For ∛54: 54 = 27 × 2 = 3³ × 2, so ∛54 = ∛(3³ × 2) = 3∛2.

When simplifying, separate the perfect power factors from the others using the rule √(ab) = √a × √b. Take the perfect powers outside the radical, and leave the remaining factors inside. For example, √72 = √(36 × 2) = 6√2, and √(4x²) = 2|x| for real x.

Simplification makes expressions easier to work with in subsequent operations. It is also a requirement when presenting final answers in examinations. Practice recognizing perfect squares (1, 4, 9, 16, 25, 36, ...) and perfect cubes (1, 8, 27, 64, 125, ...) speeds up simplification.

Surd Operations: Addition, Multiplication, and Division

Adding and subtracting surds works like collecting like terms in algebra. Only surds with the same radicand and index can be combined. For example, 3√5 + 2√5 = 5√5, but √2 + √3 cannot be combined. Always simplify surds first, as √8 + √2 = 2√2 + √2 = 3√2.

Multiplying surds uses the rule √a × √b = √(ab) when a and b are non-negative. For example, √2 × √8 = √16 = 4. This makes it possible to remove square roots when factors combine to a perfect square. More generally, ⁿ√a × ⁿ√b = ⁿ√(ab).

Dividing surds uses √a ÷ √b = √(a/b). For example, √50 ÷ √2 = √(50/2) = √25 = 5. After division, simplify the resulting surd. Division often leads to rationalization of denominators, a technique covered separately.

Rationalising the Denominator

Rationalising the denominator means removing surds from the denominator of a fraction. When a fraction has a surd denominator like 1/√3, multiply both numerator and denominator by a surd that will make the denominator rational. For 1/√3, multiply by √3/√3 to get √3/3.

For more complex denominators like 1/(2 + √3), multiply numerator and denominator by the conjugate 2 - √3. This gives (2 - √3) / ((2 + √3)(2 - √3)) = (2 - √3) / (4 - 3) = 2 - √3. The conjugate reverses the sign between terms.

Rationalisation is important because rational denominators are easier to work with in calculations and are the standard form in mathematics. Examiners expect final answers with rationalised denominators. The technique applies to any denominator containing surds or complex numbers.

Logarithms

Logarithms are the inverse operation of exponentiation. The statement a^x = b is equivalent to log_a b = x. In SHS, the most common logarithms are the base 10 logarithm log₁₀ (common logarithm) and the natural logarithm ln (base e ≈ 2.718). Logarithms provide a method to solve exponential equations and model phenomena involving growth and decay.

Learning logarithms begins with basic definitions. For example, log₁₀ 1000 = 3 because 10³ = 1000. Similarly, log₂ 8 = 3 because 2³ = 8. This inverse relationship means that logarithms answer the question "to what power must the base be raised to get this number?"

The laws of logarithms are fundamental tools for simplifying expressions and solving equations. They convert multiplication to addition, division to subtraction, and powers to coefficients. These conversions make complex exponential problems tractable.

Logarithms are the inverse of exponentials, connecting growth rates to time.

Applied Mathematics

Definition and Basic Properties

The logarithm log_a b (read "log base a of b") is the exponent to which the base a must be raised to produce b. In equation form: if a^x = b, then log_a b = x. The base a must be positive and not equal to 1. The argument b must be positive.

Important properties follow directly from the definition: • log_a 1 = 0 because a⁰ = 1 • log_a a = 1 because a¹ = a • log_a(a^x) = x because a^x = a^x • a^(log_a b) = b because log_a b is defined to satisfy this

The common logarithm has base 10 and is denoted log b or log₁₀ b. The natural logarithm has base e ≈ 2.71828... and is denoted ln b or log_e b. Most scientific calculators provide these two bases directly.

Laws of Logarithms

The product rule states: log_a(xy) = log_a x + log_a y. This means logarithm of a product equals the sum of logarithms. For example, log₁₀(100 × 1000) = log₁₀ 100 + log₁₀ 1000 = 2 + 3 = 5, and indeed 100 × 1000 = 100,000 = 10⁵.

The quotient rule states: log_a(x/y) = log_a x - log_a y. This means logarithm of a quotient equals the difference of logarithms. For example, log₁₀(1000/10) = log₁₀ 1000 - log₁₀ 10 = 3 - 1 = 2, and indeed 1000/10 = 100 = 10².

The power rule states: log_a(x^k) = k log_a x. This means the logarithm of a power equals the power times the logarithm of the base. For example, log₁₀(1000³) = 3 log₁₀ 1000 = 3 × 3 = 9, and indeed 1000³ = 10⁹.

These three laws allow students to convert between products, quotients, and powers, making complex expressions manageable. Applying the laws in reverse allows "condensing" multiple logarithms into a single logarithm.

Change of Base Rule

The change of base rule allows conversion between logarithms of different bases: log_b x = (log_a x) / (log_a b). This is essential because most calculators only provide base 10 and base e logarithms. To find log₃ 27, use log₃ 27 = (log₁₀ 27) / (log₁₀ 3) or log₃ 27 = (ln 27) / (ln 3).

The rule is derived by noting that if log_b x = y, then b^y = x. Taking log_a of both sides: log_a(b^y) = log_a x, which simplifies to y log_a b = log_a x using the power rule. Therefore, y = (log_a x) / (log_a b), and since y = log_b x, the rule follows.

Using the change of base rule: log₂ 100 = (log₁₀ 100) / (log₁₀ 2) = 2 / 0.301 ≈ 6.64. This shows that 2^6.64 ≈ 100. The rule makes it possible to calculate logarithms in any base using a calculator.

Logarithm Graphs and Applications

The graph of y = log_a x (with a > 1) passes through the point (1, 0) because log_a 1 = 0. It rises slowly to the right as x increases, approaching infinity asymptotically as x approaches infinity. There is a vertical asymptote at x = 0; the logarithm is undefined for x ≤ 0.

The graph of y = log_a x is the mirror image of y = a^x across the line y = x, reflecting the inverse relationship between logarithms and exponentials. The exponential curve rises steeply to the right, while the logarithmic curve rises slowly, showing that logarithms compress large values.

Applications of logarithms include sound intensity (decibels), pH in chemistry (acidity), earthquake magnitude (Richter scale), and compound interest formulas. In all these applications, logarithms model phenomena where small changes in the logarithmic scale correspond to large changes in the actual quantity. Mastery of logarithmic functions is essential for science and engineering.

Sets

A set is a well-defined collection of distinct objects or elements. Sets form the foundation of modern mathematics and are used to define numbers, functions, and other mathematical structures. In SHS, set theory provides the language and notation for precise mathematical communication. Elements of a set are listed or described, and each element belongs to or does not belong to the set with no ambiguity.

Sets are usually written in two ways: roster notation lists elements inside curly braces like {1, 2, 3, 4} or {red, blue, green}. Set-builder notation describes a property that elements satisfy, such as {x : x is a prime number less than 10} which means {2, 3, 5, 7}. The symbol ∈ means "belongs to" or "is an element of" a set.

Sets provide the precise language for organizing and classifying all mathematical objects.

Mathematical Language

Set Notation and Symbols

The element symbol ∈ denotes membership in a set. If a ∈ A, then a is an element of set A. If a ∉ A, then a is not an element of A. For example, 3 ∈ {1, 2, 3, 4} but 5 ∉ {1, 2, 3, 4}.

A subset B ⊆ A means every element of B is also in A. The empty set ∅ is a subset of every set. The power set P(A) is the set of all possible subsets of A. For example, if A = {1, 2}, then P(A) = {∅, {1}, {2}, {1, 2}}. A finite set with n elements has 2^n subsets.

Set cardinality |A| is the number of elements in set A. For example, |{1, 2, 3}| = 3. Two sets are equal if they contain exactly the same elements: A = B if and only if A ⊆ B and B ⊆ A. Order and repetition do not matter in sets; {1, 2, 3} = {3, 1, 2} = {1, 1, 2, 3}.

Set Operations: Union, Intersection, Complement, and Difference

The union A ∪ B contains all elements in either A or B or both. For example, {1, 2, 3} ∪ {3, 4, 5} = {1, 2, 3, 4, 5}. The intersection A ∩ B contains elements in both A and B. For example, {1, 2, 3} ∩ {3, 4, 5} = {3}. If A ∩ B = ∅, the sets are disjoint.

The complement A' (or A^c) contains all elements in the universal set U that are not in A. For example, if U = {1, 2, 3, 4, 5} and A = {1, 2}, then A' = {3, 4, 5}. The difference A − B contains elements in A but not in B. For example, {1, 2, 3} − {3, 4, 5} = {1, 2}.

De Morgan's Laws describe relationships between operations: • (A ∪ B)' = A' ∩ B' • (A ∩ B)' = A' ∪ B' These laws are useful in logic and Boolean algebra.

Venn Diagrams

Venn diagrams are visual tools for representing sets and their relationships. Typically, overlapping circles represent sets within a rectangle representing the universal set U. The overlapping region shows the intersection of sets. Non-overlapping parts show elements unique to each set. Venn diagrams make it easy to count elements and identify subsets, solve problems involving multiple conditions, and visualize relationships between sets.

To solve problems using Venn diagrams: 1) Draw circles for each set. 2) Write numbers in each region to represent the count of elements. 3) Use given information to fill in the regions. 4) Answer questions by reading totals from appropriate regions.

For example, if 30 students study Math or Science or both, 18 study Math, 20 study Science, then the overlap region has 18 + 20 - 30 = 8 students. This principle of inclusion-exclusion is fundamental in counting problems.

Algebra

Algebra is the branch of mathematics that uses symbols, usually letters, to represent numbers and relationships. Algebraic thinking allows generalization from specific examples to abstract patterns and rules. In SHS, students work with linear equations, quadratic equations, polynomials, and systems of equations. Understanding algebraic concepts prepares students for calculus and advanced mathematics.

The central feature of algebra is the use of variables—typically x, y, a, b—to represent unknown or general numbers. Equations express relationships between variables. Solving an equation means finding the values of variables that make the equation true. The power of algebra lies in its ability to solve entire classes of problems using symbolic manipulation rather than numerical trial-and-error.

Algebra is mathematics with variables, allowing general solutions to classes of problems.

Mathematical Abstraction

Linear Equations

A linear equation in one variable is of the form ax + b = c where a ≠ 0. It represents a straight line when graphed in two variables (y = mx + c). Linear equations have exactly one solution, which can be found by inverse operations: subtract b from both sides, then divide by a. The solution is x = (c - b) / a.

The graph of a linear function y = mx + c is a straight line, where m is the gradient (slope) and c is the y-intercept (where the line crosses the y-axis). The gradient m = (change in y) / (change in x) tells how steep the line is. Positive gradients slope upward to the right, negative slope downward.

Systems of linear equations are solved by substitution (solve one equation for a variable and substitute into the other), elimination (multiply equations to make coefficients equal, then subtract to eliminate a variable), or graphical methods (find the intersection point). Two lines may intersect at one point (unique solution), be parallel (no solution), or be the same line (infinitely many solutions).

Quadratic Equations

A quadratic equation is of the form ax² + bx + c = 0 where a ≠ 0. Quadratic equations can have two real solutions, one repeated real solution, or no real solutions. The quadratic formula x = (-b ± √(b² - 4ac)) / (2a) provides a general solution applicable to any quadratic.

The discriminant Δ = b² - 4ac determines the nature of roots: if Δ > 0, there are two distinct real roots; if Δ = 0, there is one repeated real root; if Δ < 0, there are no real roots (but two complex conjugate roots exist). The vertex of the parabola y = ax² + bx + c occurs at x = -b/(2a).

Factoring quadratics is an important skill. If ax² + bx + c factors as (px + q)(rx + s), then the roots are x = -q/p and x = -s/r. Not all quadratics factor over the rationals, so the quadratic formula is a universal method. Completing the square is another technique that transforms a quadratic into vertex form.

Polynomials and Factoring

A polynomial is a sum of terms with non-negative integer powers. A polynomial of degree n has the form a_n x^n + a_(n-1) x^(n-1) + ... + a_1 x + a_0. Operations on polynomials include addition, subtraction, multiplication, and division, following algebraic rules.

Factoring polynomials is essential. Standard techniques include: extracting common factors (e.g., 3x² + 6x = 3x(x + 2)), recognizing difference of squares (a² - b² = (a - b)(a + b)), sum and difference of cubes (a³ ± b³ = (a ± b)(a² ∓ ab + b²)), and grouping terms.

The factor theorem states that (x − a) is a factor of polynomial f(x) if and only if f(a) = 0. This connects roots and factors and is used to solve polynomial equations. Polynomial long division and synthetic division are algorithmic methods for dividing polynomials, essential for simplifying rational expressions.

Algebraic Inequalities

Algebraic inequalities use symbols <, >, ≤, ≥ to show relationships between quantities. Linear inequalities are solved like equations, except multiplying or dividing by negative numbers reverses the inequality sign. For example, -2x > 6 becomes x < -3 after dividing by -2.

Quadratic inequalities are solved by finding roots and testing intervals. For example, to solve x² - 5x + 6 > 0, factor to (x - 2)(x - 3) > 0, find roots 2 and 3, then test intervals: x < 2 gives (−)(−) = (+), true; 2 < x < 3 gives (+)(−) = (−), false; x > 3 gives (+)(+) = (+), true. Solution: x < 2 or x > 3.

Solution sets of inequalities are shown on number lines, with open circles for excluded endpoints and closed circles for included endpoints, or in interval notation using parentheses for excluded and brackets for included. Understanding and solving inequalities is essential for applied mathematics, optimization problems, and real-world constraints.

Trigonometry

Trigonometry is the study of relationships between angles and sides in triangles. The six trigonometric ratios are sine, cosine, tangent, cosecant, secant, and cotangent. For an acute angle θ in a right triangle: • sin θ = opposite / hypotenuse • cos θ = adjacent / hypotenuse • tan θ = opposite / adjacent These ratios extend to all angles using the unit circle, allowing trigonometric functions for any angle.

Trigonometry is foundational in physics (analyzing oscillations and waves), engineering (designing structures), surveying (measuring distances), and navigation. The subject bridges algebra and geometry, providing tools to solve problems involving angles and periodic phenomena.

Trigonometry connects angles to side lengths, solving countless practical problems.

Geometry and Physics

Trigonometric Ratios in Right Triangles

In a right triangle with angle θ (not the right angle), the opposite side is across from θ, the adjacent side is next to θ, and the hypotenuse is the longest side. The sine ratio sin θ = opposite / hypotenuse. The cosine ratio cos θ = adjacent / hypotenuse. The tangent ratio tan θ = opposite / adjacent = sin θ / cos θ.

The reciprocal ratios are cosecant csc θ = 1 / sin θ = hypotenuse / opposite, secant sec θ = 1 / cos θ = hypotenuse / adjacent, and cotangent cot θ = 1 / tan θ = adjacent / opposite.

For special angles, the ratios have exact values. For 30°: sin 30° = 1/2, cos 30° = √3/2, tan 30° = 1/√3. For 45°: sin 45° = 1/√2, cos 45° = 1/√2, tan 45° = 1. For 60°: sin 60° = √3/2, cos 60° = 1/2, tan 60° = √3. These values should be memorized for efficiency in calculations.

The Unit Circle and Extended Trigonometry

The unit circle is a circle of radius 1 centered at the origin. Any angle θ measured counterclockwise from the positive x-axis corresponds to a point on the unit circle where x = cos θ and y = sin θ. This definition extends trigonometric functions to all angles, including negative angles and angles greater than 90°.

For angles in different quadrants, the signs of trigonometric ratios change. In quadrant I (0° to 90°), all ratios are positive. In quadrant II (90° to 180°), sin is positive, cos and tan are negative. In quadrant III (180° to 270°), tan is positive, sin and cos are negative. In quadrant IV (270° to 360°), cos is positive, sin and tan are negative. The mnemonic "ASTC" (All Students Take Calculus) helps remember these signs.

The unit circle also shows that sin and cos are periodic with period 2π (360°): sin(θ + 2π) = sin θ and cos(θ + 2π) = cos θ. Tangent has period π (180°). These periodicities are fundamental to understanding periodic phenomena.

Trigonometric Identities

Trigonometric identities are equations that are true for all values of the variable. The Pythagorean identity sin²θ + cos²θ = 1 is fundamental. Dividing by cos²θ gives 1 + tan²θ = sec²θ. Dividing by sin²θ gives 1 + cot²θ = csc²θ.

Angle addition formulas allow calculation of trigonometric values for combined angles: • sin(A + B) = sin A cos B + cos A sin B • cos(A + B) = cos A cos B - sin A sin B • tan(A + B) = (tan A + tan B) / (1 - tan A tan B) These identities simplify expressions and solve trigonometric equations.

Double angle formulas are special cases of addition formulas with A = B: • sin 2θ = 2 sin θ cos θ • cos 2θ = cos²θ - sin²θ = 2 cos²θ - 1 = 1 - 2 sin²θ • tan 2θ = 2 tan θ / (1 - tan²θ) These appear frequently in calculus and applications.

Matrices

A matrix is a rectangular array of numbers arranged in rows and columns. An m × n matrix has m rows and n columns. For example, a 2 × 3 matrix has 2 rows and 3 columns: [[1, 2, 3], [4, 5, 6]]. Matrices are used to store and manipulate data, solve systems of linear equations, and represent transformations in geometry.

Matrix addition and subtraction work element-wise: corresponding elements are added or subtracted. Matrix multiplication is more complex. The entry in row i, column j of product AB equals the dot product of row i of A with column j of B. Multiplication is not commutative: AB ≠ BA in general.

The identity matrix I is the multiplicative identity: AI = IA = A for any compatible matrix A. A square matrix A has an inverse A^(-1) such that AA^(-1) = A^(-1)A = I, provided the determinant is non-zero. Inverse matrices are used to solve systems of equations: if AX = B, then X = A^(-1)B.

Vectors

A vector is a quantity with both magnitude (size) and direction. Vectors are often represented as arrows from one point to another or as ordered lists of components. In 2D, a vector is written as (a, b) or as ai + bj where i and j are unit vectors in the x and y directions. The magnitude of vector (a, b) is √(a² + b²).

Vector addition combines two vectors by placing them head-to-tail or by adding components: (a, b) + (c, d) = (a+c, b+d). Scalar multiplication stretches or shrinks a vector: k(a, b) = (ka, kb). These operations follow algebraic rules similar to ordinary numbers.

The dot product (scalar product) of two vectors u = (a, b) and v = (c, d) is u · v = ac + bd. The dot product relates to the angle between vectors: u · v = |u||v|cos θ. If u · v = 0, the vectors are perpendicular. Vectors are used extensively in physics, computer graphics, and navigation.

Calculus Basics

Calculus is the mathematics of change and accumulation. Its two main branches are differentiation (studying rates of change) and integration (studying accumulation). Calculus connects to algebra through functions and to geometry through curves and areas.

The derivative f'(x) measures the instantaneous rate of change of a function at a point. Geometrically, the derivative is the gradient of the tangent line to the curve at that point. The power rule states d/dx (x^n) = nx^(n-1). Derivatives allow finding maximum and minimum values, which is essential in optimization problems.

Integration is the reverse of differentiation. The indefinite integral ∫ f(x) dx is an antiderivative, a function whose derivative is f(x). The definite integral ∫[a to b] f(x) dx represents the area under the curve from x = a to x = b. The fundamental theorem of calculus links differentiation and integration: ∫[a to b] f'(x) dx = f(b) − f(a).

Sequences and Series

A sequence is an ordered list of numbers following a pattern. An arithmetic sequence has a constant difference d between consecutive terms: a_n = a_1 + (n−1)d. A geometric sequence has a constant ratio r: a_n = a_1 × r^(n-1). Recognizing these patterns helps find nth terms and solve problems about linear and exponential growth.

A series is the sum of terms of a sequence. The sum of the first n terms of an arithmetic sequence is S_n = n/2 (2a_1 + (n−1)d). For a geometric series with r ≠ 1, S_n = a_1(1 − r^n) / (1 − r). For an infinite geometric series with |r| < 1, the sum converges to S = a_1 / (1 − r).

Applications include financial calculations (compound interest, loan payments), population modeling, and digital signal processing. Understanding growth rates and total accumulation is essential for real-world problem solving.

Probability

Probability measures the likelihood of an event. The probability P(A) of event A is the ratio of favorable outcomes to total possible outcomes: P(A) = (number of favorable outcomes) / (total number of outcomes). Probabilities range from 0 (impossible) to 1 (certain).

Combinatorics counts arrangements and selections. Permutations count ordered arrangements: P(n,r) = n! / (n−r)!. Combinations count unordered selections: C(n,r) = n! / (r!(n−r)!). Rules of probability include P(A or B) = P(A) + P(B) − P(A and B) and conditional probability P(A|B) = P(A and B) / P(B).

Expected value is the average outcome of a random process: E(X) = Σ x × P(x). Probability distributions describe how probabilities are assigned to outcomes. The binomial distribution models n independent trials with success probability p. Applications include risk assessment, quality control, and decision-making under uncertainty.

Statistics

Statistics is the science of collecting, organizing, analyzing, and interpreting data. Descriptive statistics summarize data using averages, spreads, and visualizations. Inferential statistics use sample data to make conclusions about larger populations.

Measures of central tendency include the mean (average), median (middle value), and mode (most frequent value). Measures of spread include range, interquartile range (IQR), and standard deviation. The standard deviation σ = √[Σ(x − mean)² / n] measures average deviation from the mean.

The normal distribution (bell curve) is symmetric and described by mean μ and standard deviation σ. About 68% of data falls within μ ± σ, 95% within μ ± 2σ. Correlation measures the strength of relationship between variables, ranging from −1 to +1. Data visualization includes bar charts, histograms, scatter plots, and box plots.

Geometry and Mensuration

Geometry is the study of shapes, sizes, and properties of figures. Euclidean geometry works with points, lines, angles, triangles, circles, and other shapes. Angles sum to 180° in triangles and 360° in quadrilaterals. The Pythagorean theorem a² + b² = c² holds in right triangles.

Circles have circumference 2πr and area πr². A tangent touches at exactly one point; a chord connects two points on the circle. Triangles are classified by sides (equilateral, isosceles, scalene) or angles (acute, right, obtuse). Congruent figures have equal size and shape; similar figures have proportional sides.

Mensuration is the measurement of areas and volumes. Key formulas include: rectangle area = l×w, triangle area = (1/2)bh, circle area = πr². For solids: cylinder volume = πr²h, sphere volume = (4/3)πr³, cone volume = (1/3)πr²h. Transformations (translations, rotations, reflections) modify geometric figures.

Coordinate Geometry

Coordinate geometry combines algebra and geometry using coordinates to describe geometric figures. The Cartesian plane has perpendicular x and y axes intersecting at the origin (0,0). Every point is an ordered pair (x, y).

The distance between (x₁, y₁) and (x₂, y₂) is d = √[(x₂−x₁)² + (y₂−y₁)²]. The gradient of a line through two points is m = (y₂−y₁)/(x₂−x₁). Parallel lines have equal gradients; perpendicular lines have gradients whose product is −1.

Line equations include slope-intercept form y = mx + c, general form ax + by + c = 0, and point-slope form. A circle with center (h, k) and radius r has equation (x−h)² + (y−k)² = r². Coordinate geometry connects visual and algebraic understanding of functions and shapes.

Functions and Relations

A relation is any set of ordered pairs. A function is a special relation where each input has exactly one output. In notation, f: A → B means function f maps elements from set A (domain) to set B (codomain). The range of f is the set of all actual outputs.

Functions can be represented as equations, tables, graphs, or mappings. The vertical line test on a graph determines if a relation is a function: if any vertical line intersects the graph more than once, it is not a function. Important function types include linear, quadratic, cubic, exponential, logarithmic, and trigonometric functions.

Function composition combines two functions: (f ∘ g)(x) = f(g(x)). Inverse functions reverse the action: if f⁻¹ is the inverse of f, then f(f⁻¹(x)) = x. The graph of f⁻¹ is the reflection of f across the line y = x. Transformations of functions shift or stretch graphs, fundamental in calculus.
